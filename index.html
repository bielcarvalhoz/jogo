CIDADE DE DEUS OSASCO · SP

Núcleo Cidade de Deus (matriz do Bradesco) reconstruído a partir da planta oficial, imagens de satélite e dados do OpenStreetMap.

  • WASD andar
  • Mouse olhar
  • Shift correr
  • Espaço pular
  • F voo livre (E/Q sobe/desce)
  • M mapa (clique para se teletransportar)
  • P liga/desliga prédios procedurais
  • B limite do bairro · L placas
  • T cartoon / realista · V modo pixel
  • H ajuda · Esc pausa
  • 👆 Arraste o dedo para olhar
  • ✌️ Toque duas vezes para começar a voar para onde está olhando
  • ⬇️ Olhe para baixo para descer, para cima para subir
  • ✌️ Toque duas vezes de novo para parar de voar
  • 🗺 Mapa: toque num ponto para ir até lá
